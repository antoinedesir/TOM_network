# TOM research network

The co-authorship network, publications and PhD alumni of INSEAD's
Technology and Operations Management area.

Live at https://antoinedesir.com/TOM_network/ (GitHub Pages, served from `docs/`; antoinedesir.github.io/TOM_network/ redirects there).

`docs/` is generated by `build-preview.js` from a private source and contains
only public information. Do not edit it by hand. The original 2023 network
(pyvis) is in the git history before this change.
